What's on this tab

ESP Boards

Boards appear automatically when they publish under the site mailbox. Add another in ESPHome Site (YAML → flash), then it shows up here and in history.

    • Switches — tap to turn a relay on or off right now (manual override).
    • Daily schedule — enable an on-window; the board's clock runs it even if this page is closed.
    • Graphs tab — past values from Steward's built-in history (not for flipping switches).

    No ESP boards found yet. Power an ESP32 on the same Wi‑Fi as the Pi. If it's new, set it up under ESPHome Site, then come back — boards appear here automatically when they send messages.
